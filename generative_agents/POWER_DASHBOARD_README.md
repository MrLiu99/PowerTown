# 电力小镇用电量监控面板使用说明

## 功能概述

电力监控面板提供实时展示每个智能体在不同地点活动时的用电量消耗，包括：

1. **按位置分组的电量表格** - 每个地点（工厂宿舍、小区、学校等）显示独立的动态表格
2. **实时活动记录** - 显示每个人做了什么活动，消耗了多少电量
3. **用电量趋势图** - 展示最近24小时的用电量趋势

## 启动方式

### 1. 启动电力监控面板服务器

```bash
cd generative_agents
python power_dashboard.py
```

服务器将在 `http://127.0.0.1:5001` 启动

### 2. 访问监控面板

在浏览器中打开：
```
http://127.0.0.1:5001/power?name=power-town-test3
```

其中 `power-town-test` 是你的模拟名称。

## 界面说明

### 位置电量表格

每个位置（如"工厂宿舍"、"小区1"、"学校"等）都会显示一个独立的表格卡片，包含：

- **位置总用电量** - 该位置所有智能体的总用电量（kWh）
- **每个智能体的用电量** - 显示该位置每个智能体的总用电量
- **最近活动记录** - 显示每个人最近的活动：
  - 活动描述（如"正在睡觉"、"使用电脑"等）
  - 使用的设备（如"照明"、"电脑"、"电视"等）
  - 消耗的电量（kWh）
  - 时间戳

### 用电量趋势图

页面下方的趋势图显示：
- 最近24小时的用电量变化
- 按位置分组的曲线
- 可以直观看出不同时段的用电高峰

## API接口

### 获取实时用电量数据

```
GET /api/power/data?name={simulation_name}
```

返回格式：
```json
{
  "位置1": {
    "total_consumption": 10.5,
    "agents": {
      "智能体1": {
        "total": 5.2,
        "activities": [
          {
            "activity": "使用电脑",
            "equipment": "电脑",
            "power_kwh": 0.2,
            "timestamp": "14:30:15"
          }
        ]
      }
    }
  }
}
```

### 获取历史用电量数据

```
GET /api/power/history?name={simulation_name}&location={location}&hours={hours}
```

参数：
- `name`: 模拟名称（必需）
- `location`: 位置名称（可选，不填则返回所有位置）
- `hours`: 小时数（可选，默认24小时）

## 数据更新

- 面板默认每30秒自动刷新一次
- 也可以点击"刷新数据"按钮手动刷新
- 显示的是最近1小时内的用电量数据

## 注意事项

1. **确保模拟已运行** - 需要先运行 `start.py` 生成用电量数据
2. **数据文件路径** - 系统会从 `results/checkpoints/{simulation_name}/power/power_consumption.json` 读取数据
3. **端口冲突** - 如果5001端口被占用，可以修改 `power_dashboard.py` 中的端口号

## 示例场景

### 场景1：查看工厂宿舍用电情况

1. 访问 `http://127.0.0.1:5001/power?name=power-town-test`
2. 找到"工厂宿舍"位置卡片
3. 查看该位置所有工人的用电情况和活动记录

### 场景2：对比不同位置的用电量

1. 查看页面上的所有位置卡片
2. 对比不同位置的总用电量
3. 查看趋势图了解各位置的用电模式

### 场景3：追踪特定智能体的用电行为

1. 在位置卡片中找到目标智能体
2. 查看其最近的活动记录
3. 了解每种活动对应的电量消耗

## 故障排除

### 问题1：显示"暂无数据"

**原因**：模拟还没有运行，或者没有生成用电量数据

**解决**：
```bash
python start.py --name power-town-test --start "20250213-09:30" --step 10 --stride 10
```

### 问题2：API返回错误

**原因**：模拟名称不正确或数据文件不存在

**解决**：检查 `results/checkpoints/{simulation_name}/power/power_consumption.json` 文件是否存在

### 问题3：图表不显示

**原因**：Chart.js库加载失败

**解决**：检查网络连接，确保可以访问CDN

## 扩展功能

如果需要添加更多功能，可以：

1. **修改刷新间隔** - 在 `power_dashboard.html` 中修改 `setInterval` 的时间
2. **添加更多统计** - 在 `power_dashboard.py` 中添加新的API端点
3. **自定义样式** - 修改 `power_dashboard.html` 中的CSS样式
