# 电力系统全面升级说明

## 更新内容

### 1. 新增公共单位用电设备

已为以下公共单位添加了专门的用电设备配置：

#### 咖啡馆设备
- **咖啡馆照明** (2000W) - 营业时间7:00-22:00
- **咖啡机** (1500W) - 营业时间使用
- **咖啡馆空调** (3000W) - 营业时间使用

#### 酒吧设备
- **酒吧照明** (2500W) - 营业时间18:00-次日2:00
- **酒吧音响** (500W) - 营业时间使用
- **酒吧空调** (3000W) - 营业时间使用

#### 超市/商场设备
- **超市照明** (4000W) - 营业时间8:00-22:00
- **超市冷柜** (5000W) - 24小时运行
- **超市空调** (4000W) - 营业时间使用

#### 公共设施设备
- **公共照明** (800W) - 晚上使用
- **公共空调** (2000W) - 白天使用

### 2. 扩展活动与设备映射

新增了更多活动类型的设备映射：

#### 家庭活动
- 睡觉、休息、吃饭、阅读 → 基础照明

#### 学校活动
- 上课 → 教室照明、投影仪
- 实验 → 实验室设备、照明
- 研究 → 实验室设备、照明、电脑

#### 工厂活动
- 生产、工作 → 生产线设备、工业照明、空压机
- 检查、维护 → 工业照明

#### 商业活动
- 喝咖啡、咖啡 → 咖啡馆照明、咖啡机、咖啡馆空调
- 喝酒 → 酒吧照明、酒吧音响、酒吧空调
- 购物、购买 → 超市照明、超市冷柜、超市空调
- 用餐、聊天 → 咖啡馆照明、咖啡馆空调

#### 公共活动
- 散步、运动、等待、对话 → 公共照明

### 3. 智能位置识别

系统现在能够：
- **自动识别智能体当前位置** - 根据地址信息提取位置
- **动态更新位置** - 当智能体移动到新位置时自动更新
- **识别公共单位** - 自动识别咖啡馆、酒吧、超市、学校、工厂等公共单位

### 4. 双重记录机制

#### 个人用电量记录
- 每个智能体的活动都会记录个人用电量
- 记录在智能体的location下

#### 公共单位用电量记录
- 当智能体在公共单位活动时，会同时记录公共单位的用电量
- 记录在"公共单位"名下，location为公共单位类型（如"咖啡馆"、"酒吧"等）
- 这样可以看到每个公共单位的总用电量

## 使用效果

### 现在系统会记录：

1. **个人住宅用电** - 每个智能体在家时的用电量
2. **公共单位用电** - 咖啡馆、酒吧、超市等公共单位的总用电量
3. **所有活动** - 每个活动都会触发用电量记录（至少是基础照明）

### 监控面板显示：

在监控面板中，你可以看到：
- **个人位置** - 如"the Ville:电力小镇学院宿舍" - 显示个人用电量
- **公共单位** - 如"咖啡馆"、"酒吧"、"超市" - 显示公共单位总用电量

## 数据记录逻辑

### 记录触发条件：

1. **活动变化** - 智能体执行新活动时记录
2. **时间间隔** - 每5分钟记录一次（避免重复记录）
3. **位置变化** - 智能体移动到新位置时更新位置信息

### 记录内容：

每条用电量记录包含：
- **智能体名称** - 执行活动的智能体
- **位置** - 活动发生的位置（个人住宅或公共单位）
- **活动描述** - 智能体在做什么
- **使用设备** - 根据活动和位置自动匹配的设备
- **用电量** - 根据设备功率、使用时间、使用模式计算
- **时间戳** - 记录时间

## 示例场景

### 场景1：智能体在咖啡馆喝咖啡

- **个人记录**：智能体在"咖啡馆"位置，活动"喝咖啡"，使用"咖啡馆照明、咖啡机、咖啡馆空调"
- **公共记录**：同时记录"咖啡馆"公共单位的总用电量

### 场景2：智能体在工厂工作

- **个人记录**：智能体在"工厂"位置，活动"生产"，使用"生产线设备、工业照明、空压机"
- **公共记录**：同时记录"工厂"公共单位的总用电量

### 场景3：智能体在家休息

- **个人记录**：智能体在自己的"家"，活动"在家休息"，使用"电视、照明、空调"

## 监控面板查看

```
http://127.0.0.1:5001/power?name=power-town-test1
```

- 每个智能体的个人用电量
- 每个公共单位的总用电量

## 注意事项

1. **确保运行模拟** - 需要运行 `start.py` 生成数据
2. **数据实时更新** - 监控面板每30秒自动刷新
3. **公共单位用电量** - 显示为"公共单位"智能体，但location显示为公共单位类型
